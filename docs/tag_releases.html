Powershell post release 0.1.1

Welcome to this new release of powershell post. In this version we have lots of new features ready for users. We have added github card and dev.to card support. And removed that awefull bug where when you post it also uploads the file title-on-this-line.md. An example config that enables these new options is as follows

global_title=My Windows blog
global_description=Notes about PowerShell
global_url=NO
global_twitter_username=FALSE
global_twitter_card_image=FALSE
global_author=Ronan
global_author_url=https://example.com
global_source_url=NO
global_email=hello@example.com
number_of_index_articles=8
number_of_feed_articles=10
devto_profile=true
devto_user_name=example
github_profile=true
github_user_name=example

Happy blogging and see you on the next big release
